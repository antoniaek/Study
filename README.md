# Study — Obsidian Second Brain

This repository is designed to be used as an **Obsidian vault**. Notes are plain Markdown files, and Obsidian's `[[internal links]]` connect them into a knowledge graph.

## Start here
- [[Home]] — your main dashboard
- [[Areas/University]] — university overview
- [[Courses/Anatomy/Anatomy Hub]] — anatomy study hub
- [[Courses/Dental Studies/Dental Studies Hub]] — dental studies hub
- [[Projects/Projects Hub]] — active projects
- [[Reviews/Weekly Review]] — weekly reset
- [[Templates/Study Note Template]] — reusable study note

## Folder map
- `Areas/` — ongoing life areas and responsibilities
- `Courses/` — subjects, concepts and learning notes
- `Projects/` — outcomes with a clear finish line
- `Resources/` — useful references and tools
- `Reviews/` — weekly and term reviews
- `Templates/` — reusable note templates

## Suggested workflow
1. Capture information quickly in [[Home]] or a new note.
2. Move it to the appropriate folder when its purpose becomes clear.
3. Link concepts using `[[Note name]]`.
4. Add a short **Connections** section to important notes.
5. Review and clean up notes once a week.

## iPad setup
Open Obsidian and use this repository as the vault folder on your device. GitHub stores the Markdown files, but it does **not** automatically sync edits between Obsidian and GitHub by itself. On iPad, configure a Git-compatible sync method or use a supported Obsidian sync workflow. Before the first sync, make sure the local and remote vault contents are aligned.

Keep private information, passwords, access tokens and confidential patient information out of this repository. If the repository is public, anyone can read its contents.
